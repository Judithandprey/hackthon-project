# 录屏提纲（目标 2 分 45 秒）

网站使用正常账号和真实保存流程。先自己注册一个申请者和一个 Organizer，准备好要输入的答案。录制时隐藏密码、邀请码和 Render 环境变量。

| 时间 | 展示 | 可以解释的内容 |
|---|---|---|
| 0:00–0:20 | 首页与邮箱密码登录 | Rails MVC；支持 Hacker 和 Mentor；数据存数据库。 |
| 0:20–1:10 | 申请页，填写、Save draft、刷新、Submit | 草稿可恢复；完整性 checklist；提交后锁定。 |
| 1:10–1:25 | 展示 Mentor 账号的表单 | 与 Hacker 问题不同，多了 mentoring approach 和 availability。 |
| 1:25–2:10 | Organizer 登录、列表、筛选、blind review、评分 | 三项 rubric，每项 1–5 分；private notes；选择 Accepted 并保存。 |
| 2:10–2:30 | 回到申请者登录并刷新 | 状态已经更新，看不到 organizer 的私密 notes。 |
| 2:30–2:45 | 仓库目录和一个测试 | 展示 models/controllers/views、migration、RSpec 和 Cucumber。 |

如重复录制需要全新申请，请创建另一个申请者账号；已提交申请保持只读。先完成一次真实流程，录制时不要把测试结果说成线上验证。

提交前确认 GitHub 仓库、Render 网站和视频都能被评委打开。录屏文件最长 3 分钟。
